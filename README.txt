JOSHUA DE LEON — STATIC PORTFOLIO
=================================

WHAT'S INCLUDED
- index.html: all portfolio sections and content
- assets/style.css: responsive styling and visual design
- assets/script.js: mobile navigation and dynamic footer year

HOW TO VIEW
1. Extract the ZIP file.
2. Open the index.html file in Chrome, Edge, Firefox, or another modern browser.
3. No server, database, npm install, or build step is required.

BEFORE PUBLISHING — PERSONALIZE THESE DETAILS
1. In index.html, replace your.email@example.com with your real contact email.
2. Add your GitHub and LinkedIn links when ready.
3. Add project screenshots, repository links, and verified outcomes.
4. Review all role, project, and skills descriptions for accuracy.
5. If you prefer a fully offline website, remove the Google Fonts <link> elements in index.html; system fonts will be used as fallbacks.

PUBLISHING
You can upload the extracted files to GitHub Pages, Netlify, Cloudflare Pages, or any static web host. Keep the index.html file at the published site's root.

This is a static portfolio template. Contact actions use an email link; there is no backend contact form.
